# Grace Chen Resume Site

這是可直接部署至 GitHub Pages 的靜態履歷網站，無需安裝套件或建置步驟。

## 部署到 GitHub Pages

1. 在 GitHub 建立新的 repository。
2. 將此資料夾內的所有檔案推送至 repository 的 `main` 分支。
3. 在 repository 的 **Settings → Pages**，選擇 **Deploy from a branch**。
4. 選擇 `main` 分支與 `/ (root)` 資料夾後儲存。

GitHub 會產生可分享的網站網址。

## 編輯內容

- 主要文字內容位於 `index.html`。
- 視覺樣式位於 `styles.css`，專案頁籤互動位於 `tabs.js`。
- 個人照片位於 `assets/grace-chen.jpg`；若替換照片，請維持此檔名或同步更新 HTML 中的圖片路徑。
